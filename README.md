Assignment number 1: Creating a personal Website

Project Description:
This project is a personal portfolio website created using HTML5 and CSS3. The purpose of the website is to introduce myself, showcase my programming projects, and provide visitors with a way to contact me.

The website contains four separate HTML pages and uses CSS stylesheets to create a consistent design across desktop, tablet and phone screens. 

Website Pages:

The website contains the following four HTML pages:

index.html(Home Page): The main page that welcomes visitors and introduces the website.
about.html(About me page): Contains my personal photo, a short biography and an introduction video with control and a poster image.
projects.html(Projects.html): Displays descriptions of five programming projects: Weather App, File Copy Program, ATM Program, Even and Odd Numbers and String Information.
contact.html(Contact Me Page): Contains a contact form with first name, last name, email, phone number, comments and favourites-colour feilds. It also includes reset and submit buttons.

All four pages contain a navigation menu that allows visitor to move between the pages and a footer containing my email address and copyright information.

Other Project Files:

The following files are used to support the website

style.css: The main stylesheet containing the general design, colours, typography, navigations, footer, form styling and gradients.
desktop.css: Contains additional styling for desktop screens with a minimum width of 960px.
tablet.css: Contains styling adjustments for tablet screens between 481px and 959px.
phone.css: Contains styling adjustments for phone screens with maximum of  480px.
photo.png: The image used for my profile picture and other photo areas on the website.
poster.png: The poster image display before the introduction video plays.
introduction.mp4: The MP4 version of my introduction video.
introduction.ogv: An alternative OGV version of my introduction video for browser compatibility.
README.md: This file, which documents the project, design choices, validation results and testing.

HTML and CSS Techniques:

The websites uses HTML semantic elements to organize its content, including headings, paragraphs, navigation, sections, articles, forms and footers.

CSS3 is used to control the website's layout, colours, backgrounds, borders, spacing, typography and responsive appearance. The website uses a fluid design with separate stylesheets for desktop,tablet and phone screens. Flexbox is not used.

The website uses the following screen-width ranges:

Phone: 480px and below, using phone.css.
Tablet: 481px and above, using tablet.css
Desktop: 960px and above, using desktop.css.

Media queries are also used to adjust certain styles when the screen size changes.

Gradients

The website includes two types of linear gradient:

Linear gradient: A horizontal gradients used in the header background.
Angled linear gradient: A gradient set to 135 degrees, used in the welcome box background.

Validation and Testing:
I tested the websites using all the validation and testing tools specified in the assignment. I corrected the reported HTML errors and checked the website again. The results below describe the final checks.

W3C Markup Validation Service

Website: https://validator.w3.org/

Result: All four HTML pages were checked and no errors were reported after the corrections.

Two HTML issues were corrected:

1. In about.html, the photo-banner element was changed from a section element to a div element to resolve the reported validation error.
2. In contact.html, the required attribute was removed from the favourite-colour input because the validator reported an error with that attribute on the colour input.

After making these changes, the HTML validation checks showed no errors.

W3C CSS Validation Service

Website: https://jigsaw.w3.org/css-validator/

Result: The CSS stylesheet were checked individually, and no errors were reported.

W3C Link Checker

Website: https://validator.w3.org/checklink

Result:The website was checked for link errors, and the tool reported on errors.

WAVE Accessibility Evaluation Tool

Website: https://wave.webaim.org/

Result: The website was checked using WAVE, and no accessibility errors were reported by the tool.

Spelling Check - Grammarly

Website: https://www.grammarly.com/

Result: Grammarly was used to check the spelling of the website's text. The spelling mistake "demostrates" in the Weather App description was corrected to "demonstrates".

All the validation and testing tools listed above were used to check the website and the reported issues were corrected where necessary.
