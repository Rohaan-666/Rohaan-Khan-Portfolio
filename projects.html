MY PROJECTS

Project 1 - Weather App

This group project retrieves current weather information for a city using the OpenWeatherMap API. It demonstrates Python functions, conditionals, loops, modules, input validation, error handling and formatted output.

Project 2 - File Copy Program

This Python program reads information from an input file and copies it to an output file. It also counts lines and characters, checks whether files exist, and appends additional information to the output.

Project 3 - ATM Program

This Python program simulates basic ATM operations. It allows the user to view balances, deposit money, withdraw money, transfer money and exit through a menu.

Project 4 - Even and Odd Numbers

This Python program separates numbers into even and odd lists and calculates their averages. It also calculates powers using the position of each number in the list.

Project 5 - String Information

This Python program examines strings and reports information such as words, characters, letters, numbers, punctuation, uppercase and lowercase characters, spaces and reversed text.
